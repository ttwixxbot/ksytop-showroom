# Зона Комфорта · предпросмотр шоурума

[Открыть сайт](https://ttwixxbot.github.io/ksytop-showroom/)

[Скриншот главной](preview/home.png)

Главная с интерьерной сценой, лентой категорий, подборками и карточками мебели. В слайдере можно менять сцены вручную и свайпом. Поиск ведёт к товарным карточкам, а отмеченные модели сохраняются в браузере.

В репозитории находится статический экспорт Next.js для GitHub Pages. Каталогу не требуется сервер приложений. Указанные цены являются ориентирами производителя или примерами комплектаций. Форма открывает черновик в почтовом приложении без адреса получателя.

Для локального просмотра клонируйте репозиторий в папку с именем `ksytop-showroom`. Запустите команду из родительской папки и откройте `http://127.0.0.1:4191/ksytop-showroom/`.

```powershell
python -m http.server 4191 --bind 127.0.0.1
```

Фотографии мебели принадлежат соответствующим правообладателям.
